# For Yuki ♡

A tiny static date-night chooser for Zürich.

## Publish with GitHub Pages

1. Upload `index.html`, `style.css`, and `script.js` to the repository root.
2. GitHub → Settings → Pages.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. The site should appear at `https://peiyuanjing.github.io/yuki/`.

The displayed times are proposed date choices, not live restaurant availability.
